1. Pendahuluan

Aplikasi GAS PDE (SO Faktur Jual) adalah sistem manajemen Stock Opname (SO) faktur penjualan yang terintegrasi dengan Accurate Online. Aplikasi ini memfasilitasi proses verifikasi keberadaan fisik faktur, pelacakan piutang, dan broadcast tagihan otomatis via WhatsApp.

1.1 Login dan Autentikasi

Untuk mengakses aplikasi, buka URL aplikasi di browser. Halaman login akan tampil meminta:

FieldKeterangan
UsernameNama pengguna yang telah didaftarkan oleh Admin
PasswordKata sandi pengguna
ℹ️ Catatan Sesi login disimpan dalam cookie browser. Jika Anda menutup semua tab browser, Anda akan diminta login kembali.

1.2 Peran Pengguna (Roles)

RoleHak Akses
ADMIN Akses penuh: Dashboard, SO Release, SO Process, Adjustment, Piutang, Settings, Absensi Faktur, System Logs
FINANCE Dashboard, SO Adjustment (Approval), Piutang (termasuk Settings Broadcast), Absensi Faktur
STAFF Dashboard, SO Process (scan faktur), Piutang (tanpa Settings), Absensi Faktur

2. Dashboard

2.1 Halaman Utama Dashboard

Dashboard menampilkan daftar semua periode SO yang telah dibuat. Setiap kartu periode menampilkan:

  • Nama Periode — judul sesi SO (contoh: "SO Minggu 4 Januari 2026")
  • Status — OPEN, SUBMITTED, atau FINALIZED
  • Jumlah Faktur — total faktur dalam periode tersebut
  • Tanggal Dibuat

Klik pada kartu periode untuk membuka halaman SO Process (jika OPEN) atau Adjustment (jika SUBMITTED/FINALIZED).

2.2 Navigasi Menu

Header dashboard berisi navigasi utama:

TombolFungsiAkses

Absensi FakturKe halaman absensi faktur harianSemua role

3. SO Release — Buat Periode Baru

Menu SO Release digunakan untuk menarik data faktur dari Accurate Online dan membuat periode Stock Opname baru. Data yang ditarik akan disalin ke database lokal sehingga perubahan di Accurate setelahnya tidak mempengaruhi sesi SO yang sedang berjalan.

3.1 Filter Data Accurate

FilterOpsiKeterangan
Nama Periode/SesiTeks bebasWajib diisi. Contoh: "SO Minggu 4 Jan 2026"
Status PiutangBelum Lunas / Lunas / SemuaDefault: Belum Lunas (Outstanding)
Status AccurateTeks bebas (opsional)Contoh: "Dihapus" untuk filter status tertentu
Filter CabangDropdown cabang (opsional)Kosongkan untuk semua cabang
Dari TanggalDate picker (opsional)Batas awal tanggal faktur
Sampai TanggalDate picker (opsional)Batas akhir tanggal faktur

3.2 Proses Release

1
Isi Nama Periode

Berikan nama deskriptif untuk periode SO yang akan dibuat.

2
Atur Filter (opsional)

Sesuaikan filter data sesuai kebutuhan: status piutang, cabang, dan rentang tanggal.

3
Klik "Release Data SO"

Sistem akan menarik data dari Accurate secara batch. Progress akan ditampilkan secara real-time (jumlah faktur yang ditarik per halaman).

4
Selesai

Setelah selesai, Anda diarahkan kembali ke Dashboard. Periode baru muncul di daftar dan siap diproses.

⚠️ Penting Jangan tutup halaman saat proses release berlangsung. Data yang sudah di-release merupakan snapshot — perubahan di Accurate setelahnya tidak akan tercermin.

4. SO Process — Scan Faktur

Halaman SO Process adalah area utama kerja Stock Opname. Di sini, petugas memverifikasi keberadaan fisik faktur dengan cara scan barcode atau input manual nomor faktur.

4.1 Scan Barcode

1
Gunakan Barcode Scanner

Arahkan barcode scanner (hardware) ke barcode pada faktur fisik. Scanner akan otomatis mengirim nomor faktur ke field input.

2
Verifikasi Otomatis

Sistem akan mencocokkan nomor faktur yang discan dengan data SO. Jika cocok, status berubah dari UNVERIFIED ke MATCHED.

StatusIkonKeterangan
MATCHED✅Faktur ditemukan dan cocok — sudah di-scan
UNVERIFIED⚠️Faktur belum di-scan / belum diverifikasi

4.2 Input Manual

Selain scan, Anda bisa mengetik nomor faktur secara manual di field "Ketik No. Faktur" lalu tekan Enter atau klik tombol "Scan".

4.3 Scan via Kamera

Klik tombol 📷 Kamera untuk membuka scanner menggunakan kamera perangkat. Arahkan kamera ke barcode faktur. Fitur ini berguna untuk perangkat mobile (HP/tablet) yang tidak memiliki barcode scanner hardware.

4.4 Filter dan Sortir Data

Di bagian atas tabel, tersedia tombol Filter yang membuka panel filter dengan opsi:

FilterOpsi
Status ScanSemua / MATCHED / UNVERIFIED
Status KeberadaanSemua / ADA / HILANG / Dibawa Sales

Klik header kolom pada tabel untuk sortir data berdasarkan kolom tersebut (ascending/descending).

4.5 Status Keberadaan Faktur

Setiap faktur memiliki kolom Keberadaan yang dapat diubah melalui dropdown:

StatusKeterangan
ADAFaktur fisik ditemukan dan ada di tempat
HILANGFaktur fisik tidak ditemukan / hilang
Dibawa SalesFaktur sedang dibawa oleh sales (diset otomatis via Absensi Faktur)
— (Kosong)Belum diverifikasi keberadaannya

Kolom Keterangan Tambahan (Remarks) dapat diisi untuk catatan tambahan, misalnya: "dipinjam oleh Pak Andi" atau "fotokopi".

4.6 Export Data

Klik tombol "Export" untuk mengunduh data SO dalam format file yang dapat dibuka di spreadsheet.

5. SO Adjustment & Finalisasi

Halaman Adjustment menampilkan ringkasan hasil SO dan memungkinkan review sebelum submit untuk approval.

5.1 Review Data

Bagian atas menampilkan 4 kartu ringkasan:

KartuKeterangan
Total FakturJumlah seluruh faktur dalam periode
Verified (Match)Faktur yang sudah di-scan dan cocok
Selisih / Belum OKFaktur yang belum ter-scan (perlu perhatian)
Hilang & SalesRincian faktur hilang dan faktur yang dibawa sales

Filter tersedia untuk menampilkan data berdasarkan kategori:

  • Semua Data — tampilkan semua faktur
  • Selisih Only — hanya faktur yang belum terverifikasi
  • Hilang — hanya faktur berstatus HILANG
  • Dibawa Sales — hanya faktur yang dibawa sales

5.2 Submit for Approval

Setelah review selesai, klik tombol "Submit for Approval" untuk mengunci data dan meminta persetujuan Finance. Setelah submit:

  • Status sesi berubah menjadi SUBMITTED
  • Data menjadi read-only — tidak bisa diedit lagi
  • Menunggu persetujuan dari Finance/Admin

5.3 Export XLSX & PDF

Setelah sesi berstatus FINALIZED, tombol export tersedia:

FormatKeterangan
XLSXDownload sebagai file Excel untuk analisis lebih lanjut
PDFDownload sebagai dokumen PDF untuk arsip/cetak

6. Piutang (Receivables)

Menu Piutang menampilkan data tagihan customer yang ditarik dari Accurate Online. Dilengkapi dengan fitur broadcast tagihan via WhatsApp.

6.1 Sync Data dari Accurate

1
Pilih Cabang (opsional)

Gunakan dropdown cabang untuk memfilter data per cabang. Biarkan kosong untuk semua cabang.

2
Klik "Force Sync" (🔄)

Sistem menarik data piutang terbaru dari Accurate. Proses ini membutuhkan beberapa saat tergantung jumlah data.

6.2 Broadcast WhatsApp

Klik tombol "Broadcast" untuk mengirim pesan tagihan ke semua customer yang memiliki piutang. Pesan dikirim via WAHA (WhatsApp HTTP API).

ℹ️ Prasyarat Broadcast Konfigurasi WAHA harus sudah diatur di halaman Piutang → Settings. Pastikan koneksi WAHA aktif dan session WhatsApp terhubung.

6.3 Detail Customer

Tabel piutang menampilkan:

KolomKeterangan
CustomerNama customer
KontakNomor telepon customer (untuk WhatsApp)
Jml InvoiceJumlah faktur yang belum lunas
Total TagihanTotal nominal piutang customer
ActionTombol untuk melihat detail faktur

7. Pengaturan Broadcast & Jadwal

Diakses melalui Piutang → Settings (hanya untuk role ADMIN dan FINANCE).

7.1 Konfigurasi WAHA

WAHA (WhatsApp HTTP API) adalah gateway untuk mengirim pesan WhatsApp. Konfigurasi yang diperlukan:

FieldKeteranganContoh
WAHA API URLURL server WAHA Andahttps://waha.example.com
Session IDID sesi WhatsApp di WAHAdefault
API KeyKunci API (opsional)secret_key

Gunakan tombol "Test Connection" untuk menguji koneksi. Masukkan nomor HP tujuan, lalu klik Test. Jika berhasil, pesan test akan terkirim ke WhatsApp tujuan.

7.2 Broadcast Testing

Fitur testing memungkinkan Anda menguji template broadcast sebelum digunakan secara massal:

1
Pilih Customer (Data Source)

Pilih customer yang datanya akan digunakan untuk mengisi variabel template.

2
Masukkan Nomor HP Tujuan Test

Pesan dikirim ke nomor ini (bukan ke customer). Masukkan nomor Anda sendiri untuk pengujian.

3
Edit Template (opsional)

Sesuaikan template pesan. Variabel yang tersedia: {customerName}, {totalOwing}, {invoiceList}

4
Klik "Kirim Test Broadcast"

Cek WhatsApp Anda untuk memastikan format pesan sesuai harapan.

7.3 Jadwal Otomatis (SYNC & BROADCAST)

Sistem mendukung penjadwalan otomatis untuk dua jenis tugas:

TipeKeterangan
Auto Sync AccurateMenarik data piutang dari Accurate secara otomatis sesuai jadwal
Auto Broadcast WAMengirim pesan tagihan ke customer secara otomatis sesuai jadwal

Parameter Jadwal

ParameterOpsiKeterangan
FrekuensiSetiap Hari / Setiap Minggu / Setiap BulanKapan jadwal dijalankan
Hari (Mingguan)Senin–MingguHanya untuk frekuensi mingguan
Tanggal (Bulanan)1–31Hanya untuk frekuensi bulanan
JamTime pickerWaktu eksekusi
StatusAktif / Non-AktifToggle on/off

Parameter Khusus — Auto Sync

  • Pilih Cabang — filter cabang untuk sync (kosongkan untuk semua cabang)
  • Status Invoice — Belum Lunas / Lunas / Semua
  • Rentang Tanggal — dari tanggal & sampai tanggal (opsional)

Parameter Khusus — Auto Broadcast

  • Template Pesan — template dengan variabel {customerName}, {totalOwing}, {invoiceList}
  • Min. Umur Faktur — hanya kirim jika umur faktur ≥ X hari
  • Min. Lewat Jatuh Tempo — hanya kirim jika sudah lewat jatuh tempo ≥ X hari

Menu Absensi Faktur digunakan untuk melacak faktur harian yang dibawa oleh sales. Fitur ini memastikan setiap faktur yang keluar tercatat dan diketahui statusnya — apakah masih di tangan sales atau sudah dikembalikan.

8.1 Membuat Sesi Absensi

1
Buka menu Absensi Faktur

Klik "Absensi Faktur" di header Dashboard.

2
Klik "+ Sesi Baru"

Dialog form akan muncul. Isi:

FieldKeterangan
Nama Sales *Nama sales yang membawa faktur hari ini
TanggalTanggal absensi (default: hari ini)
CatatanCatatan tambahan (opsional)

8.2 Menambah Faktur (Manual & Scan)

Di halaman detail sesi, terdapat dua cara menambahkan faktur:

A. Input Manual dengan Autocomplete

1
Ketik di field "No. Faktur"

Saat mengetik, sistem akan menampilkan saran (autocomplete) dari data SoItem yang tersimpan. Daftar saran menampilkan nomor faktur, nama customer, dan nominal.

2
Pilih dari saran atau isi manual

Klik saran untuk mengisi otomatis semua field, atau isi manual jika faktur tidak ada di data SO.

3
Klik "Tambah"

Faktur ditambahkan ke daftar dengan status Dibawa.

B. Scan Barcode via Kamera

1
Klik tombol "Scan Barcode" (biru)

Kamera perangkat akan terbuka dengan scanner barcode.

2
Arahkan ke barcode faktur

Nomor faktur otomatis terisi. Jika cocok dengan data SO, field customer dan nominal juga otomatis terisi.

3
Klik "Tambah"

Faktur ditambahkan ke daftar.

8.3 Terima Kembali Faktur

Saat sales mengembalikan faktur, klik tombol ✅ (centang hijau) pada baris faktur. Status berubah dari Dibawa menjadi Kembali beserta timestamp pengembalian.

Jika ingin membatalkan pengembalian, klik tombol ↩ (undo) — status kembali ke Dibawa.

Filter tersedia untuk menampilkan faktur berdasarkan status:

  • Semua — tampilkan semua faktur
  • Dibawa — hanya faktur yang masih di tangan sales
  • Kembali — hanya faktur yang sudah dikembalikan

8.4 Sync ke SO

Tombol "Sync ke SO" di halaman utama Absensi Faktur akan menyinkronkan data absensi ke module SO:

✅ Efek Sync
  • Faktur dengan status Dibawa (OUT) → SoItem di-update:
    — existenceStatus = "Dibawa Sales"
    — status = "MATCHED" (scan OK)
    — remarks = "Dibawa oleh: [nama sales] ([tanggal])"
  • Faktur dengan status Kembali (RETURNED) → SoItem di-reset:
    — existenceStatus = null
    — remarks = null

11. FAQ — Pertanyaan Umum

Q: Apakah data SO bisa diedit setelah Submit?

A: Tidak. Setelah Submit for Approval, data terkunci (read-only). Hubungi Admin jika perlu perubahan — Admin dapat membuka kembali sesi.

Q: Bagaimana jika barcode faktur tidak terbaca?

A: Gunakan input manual — ketik nomor faktur di field yang tersedia lalu tekan Enter. Anda juga bisa menggunakan fitur scan kamera.

Q: Apa bedanya SO Process dan Adjustment?

A: SO Process adalah tahap scan/verifikasi keberadaan faktur. Adjustment adalah tahap review hasil scan sebelum submit untuk approval.

Q: Kenapa broadcast WhatsApp tidak terkirim?

A: Pastikan:
1) Konfigurasi WAHA sudah benar (URL, Session ID, API Key)
2) Session WhatsApp aktif (tidak terputus)
3) Test Connection berhasil
4) Nomor HP customer dalam format internasional (628xxx)

Q: Bagaimana cara faktur otomatis bertanda "Dibawa Sales" di SO?

A: Gunakan menu Absensi Faktur: buat sesi → tambahkan faktur → jika belum dikembalikan, klik "Sync ke SO". Faktur tersebut akan otomatis bertanda "Dibawa Sales" dengan status scan OK di SO.

Q: Apakah jadwal broadcast bisa diatur per cabang?

A: Untuk tipe Auto Sync, parameter cabang bisa diatur. Untuk Auto Broadcast, broadcast dikirim ke semua customer yang memiliki piutang sesuai filter umur faktur dan jatuh tempo yang dikonfigurasi.

Q: Bisakah satu faktur muncul di beberapa sesi absensi?

A: Ya, satu nomor faktur bisa muncul di sesi berbeda. Saat Sync, jika ada satu sesi yang masih menandai faktur sebagai "Dibawa", status di SO tetap "Dibawa Sales".
